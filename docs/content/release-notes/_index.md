fb follows semantic versioning.
Before 1.0 the command surface can still move between minor versions, and v0.3.0 moved most of it.

- [v0.3.0](/release-notes/v0-3-0/): rewritten against the Comet data plane. Every data source changed and mbasic is gone.
- [v0.2.0](/release-notes/v0-2-0/): a breadth-first walk of the graph from any seed.
- [v0.1.2](/release-notes/v0-1-2/): public groups read in full, with posts and comments.
- [v0.1.1](/release-notes/v0-1-1/): reads Facebook without a cookie, plus a new archive command.
- [v0.1.0](/release-notes/v0-1-0/): the first release.
